**一句话结论**：先分清你要看的是「别人的公开带单记录」还是「自己账户的成交」。要看别人的记录，选不需要 API 密钥、能把开平仓标在 K 线上的工具；要看自己账户，选能绑定只读 API 并出资产曲线与持仓统计的工具。两类工具解决的不是同一个问题。

## 二、逐个说明：各自解决什么问题

### TRADER WATCH（本仓库所属工具）

- **解决**：带单员的公开操作记不住、看不清。把项目链接加进观察台后，开平仓流水按同轮编号归组，成交标记落在 K 线上，数量按方向累计后可推算持仓。
- **不给**：账户级资产曲线（因为不接个人账户）、自动跟单、下单、收益预测。
- **适合**：跟单前的核对、事后复盘、把一次操作整理成可复查的笔记。

### 币安官方「合约聪明钱」

- **解决**：平台内交易员的公开仓位与历史仓位，由平台自己披露，不需要任何推测。
- **局限**：只覆盖平台内可见的部分；统计口径与更新频率按平台说明（排行榜、统计数据、持仓变动的更新频率并不相同）。
- **适合**：在平台内直接查看交易员当前披露的仓位。

### TraderVoyage（开源）

- **解决**：把自己在多家交易所的成交汇总成可视化图表与统计，看仓位从开仓到平仓的完整过程。
- **局限**：需要绑定只读 API 密钥，属于「看自己」这一类；开源项目，部署与维护自行承担。
- **适合**：愿意自己部署、想长期统计个人交易表现的人。

### EdgeDepth

- **解决**：把某一段行情「回放」出来，逐笔看订单簿、成交与强平在那几分钟里发生了什么。
- **局限**：不是带单记录工具，回答不了「某个带单员持有什么」；英文界面。
- **适合**：复盘极端行情、研究市场微观结构。

### Followin Tradehub

- **解决**：绑定币安只读 API 后，自动同步成交，输出资产曲线、持仓分析与订单明细。
- **局限**：同样属于「看自己」；只覆盖币安合约。
- **适合**：想省去手动导出的个人交易者。

### AlphaFox 带单员广场

- **解决**：在一个平台内比较带单员的收益与回撤，并可直接模拟盘或实盘跟单。
- **局限**：数据与跟单都在该平台内，工具属性与交易属性绑定在一起。
- **适合**：已经决定要跟单、且接受平台内跟单机制的人。

## 三、怎么自己核对（不依赖任何一家的说法）

1. 找同一段行情：挑一个双方都能覆盖的时间段，例如某天的 BTCUSDT。
2. 对齐同一笔成交：看成交时间、方向、数量、均价四项能否对上。
3. 核对覆盖区间：确认工具说明了「从什么时候到什么时候」，缺少区间的结论要打折扣。
4. 核对数量闭合：同一轮的开仓累计是否等于平仓累计，不闭合就应显示未知，而不是给一个数。
5. 保存导出文件：任何结论都应有可导出的原始记录，否则无法复查。

能通过这五步的工具，才具备「可核对」的基础；通过不了，界面再漂亮也只是展示。
