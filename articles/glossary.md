# 公开带单记录术语表：带单员、公开仓位与推算持仓的6个概念

原文链接 https://bn.9987620.xyz/glossary

TRADER WATCH · 发布于 2026-11-19 · 更新于 2026-11-21

查询带单员持仓时，得到的往往是带时间和覆盖条件的记录。先区分这6个概念，再判断一个数量是否有充分依据。

## 1. 带单员（带单交易员 / 项目ID）

在币安带单项目中对外展示其交易组合的交易员。核对时应使用项目ID，昵称不能作为唯一标识。

常见误读：同名就是同一项目。使用方法：从官方带单主页保留项目ID，再添加监控。

资料：[对应说明与核对方法](https://bn.9987620.xyz/guide)

## 2. 公开成交流水（公开记录）

平台公开页面或接口可取得的成交操作，包含时间、方向、数量与成交均价；有记录不等于记录完整。

常见误读：已取得的流水就是全部历史。使用方法：一起检查查询区间、分页覆盖与查询截止时间。

资料：[对应说明与核对方法](https://bn.9987620.xyz/articles/copy-trader-position-history-mistakes)

## 3. 公开仓位（披露仓位）

平台在特定时刻对外披露的持仓信息。它应与披露时间一起阅读，不保证此后仍保持相同数量。

常见误读：旧快照代表此刻的账户。使用方法：分清披露仓位、成交流水和本站推算。

资料：[对应说明与核对方法](https://bn.9987620.xyz/articles/binance-trader-position-query)

## 4. 推算持仓

从可靠起点开始，对同一项目、同一合约、同一方向累计开仓并扣减平仓所得的数量。它是本站依据所覆盖记录的推算。

常见误读：推算结果等于隐藏账户的实时真实仓位。使用方法：结论同时保留起点、覆盖范围、查询截止时间及不确定原因。

资料：[对应说明与核对方法](https://bn.9987620.xyz/methodology)

## 5. 全平基线（可靠起点）

能核对某合约某方向数量归零的时点。另一种可用起点是从项目开始具有完整覆盖的记录；不能任意选一条最早成交作为零状态。

常见误读：基线不明也能确定剩余数量。使用方法：缺少可核对起点或存在记录缺口时保留数据不足。

资料：[对应说明与核对方法](https://bn.9987620.xyz/methodology)

## 6. 同轮编号

按相同合约、方向与数量归组的一组开仓、加仓及平仓的编号，数量归零后结束该轮；它不是原始委托的一一配对。

常见误读：图表上连接的成交必然是一对原始订单。使用方法：结合整轮数量和覆盖依据复查。

资料：[对应说明与核对方法](https://bn.9987620.xyz/articles/kline-review-entry-exit-connections)
