# 术语表：看懂带单记录前先分清这 6 个词

> 网站原文：https://bn.9987620.xyz/glossary ｜ 更新：2026-11-19

很多人把「带单员持仓查询」当成查一个数字，实际得到的是一个带条件的结论。下面 6 个词决定了这个结论能不能成立。

## 1. 带单员（带单交易员 / 项目 ID）

**一句话**：在币安带单项目里公开自己交易组合的交易员；每个项目有唯一 ID，昵称可以重名，项目 ID 不能。

**常见误读**：按昵称搜索，搜到同名的另一个人。

**怎么用**：从带单主页链接里取项目 ID，再用 ID 添加监控目标。

→ 参考：[KOL 喊单复盘六项清单](kol-trade-review-checklist.md)

## 2. 公开成交流水（公开记录）

**一句话**：平台公开页面上能取得的开仓、平仓记录，包含时间、方向、数量与成交均价。

**常见误读**：把「有记录」当成「记录完整」。分页、区间缺口、采集延迟都会让流水不完整。

**怎么用**：先看覆盖区间与查询截止时间，再谈数量。

→ 参考：[跟单复盘里的 5 个常见误区](copy-trader-position-history-mistakes.md)

## 3. 公开仓位（披露仓位）

**一句话**：平台在某一时刻对外披露的持仓状态，是「那一刻」的快照，不是持续保证。

**常见误读**：把披露时间当成当前时间。

**怎么用**：任何仓位数字都要和披露时间一起读。

→ 参考：[币安交易员持仓查询](binance-trader-position-query.md)

## 4. 推算持仓

**一句话**：用公开流水按数量累加得到的结果 —— 可靠起点之后，同合约同方向的累计开仓减去累计平仓。

**常见误读**：把它当成「实时真实仓位」。它只是已覆盖记录范围内的净数量。

**怎么用**：结论必须同时给出起点、覆盖区间与查询截止时间；三者缺一，就不该给出数字。

→ 参考：[数据与推算方法](https://bn.9987620.xyz/methodology)

## 5. 全平基线（可靠起点）

**一句话**：能确认「此刻该合约该方向数量为零」的那个时点，之后的累计从零开始算。

**常见误读**：随便挑一条最早的记录当起点，然后得到偏大的净数量。

**怎么用**：找不到可确认的零状态，就应显示「数据不足」，而不是硬算一个数。

→ 参考：[47.241 BTC 开空记录之后还发生了什么](aoying-kline-review-btc-202610.md)

## 6. 同轮编号

**一句话**：把同一合约、同一方向、数量上相互对应的一组开仓与平仓归为同一轮，用于把加仓、分批平仓放到同一条线上。

**常见误读**：把不同方向或不同轮的成交连成一条线，看起来合理，实际错误。

**怎么用**：点击同轮编号定位整轮，再看数量是否闭合。

→ 参考：[把开仓、加仓和分批平仓连起来](kline-review-entry-exit-connections.md)
