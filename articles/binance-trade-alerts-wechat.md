# 币安成交微信推送｜交易员开平仓提醒与 ClawBot 设置

原文链接 https://bn.9987620.xyz/articles/binance-trade-alerts-wechat

TRADER WATCH · 发布于 2026-11-26 · 更新于 2026-11-26

想把币安交易员的新成交推送到微信，可以用 TRADER WATCH 的微信 ClawBot 成交提醒。网站采集到正在监控的交易员的新公开成交后，会发送到你的个人微信。用邀请码注册，扫码绑定并发送 init 后即可接收。提醒默认开启，支持设置静默时段。

## 微信推送可以提醒哪些币安成交？

想知道观察中的交易员有没有开仓、加仓、减仓或平仓，可以让观察台在云端采集后向微信发消息。它适合在收到提醒后打开原记录，核对交易时间、数量和当时的行情。

提醒覆盖网站正在监控的目标。推送内容来自币安公开记录，无须绑定个人币安账户或提供个人币安 API 密钥。接收消息不会发起任何交易。

网页关闭后，微信仍可接收云端采集的提醒。到达时间取决于公开记录更新、本站采集和微信投递，收到提醒后可以回档案核对原始记录。

## 怎么开通币安成交微信推送？

第一步，用管理员提供的邀请码在微信通知网关注册，然后登录通知面板。已有网关账号可以直接登录。

第二步，在「微信绑定」卡片点击「扫码绑定」，用微信扫描二维码并确认。随后打开微信里的 ClawBot 聊天，发送一条 init，等待面板显示已激活。

第三步，确认「TRADER WATCH 成交提醒」已开启。注册时默认开启，设置在微信通知面板里保存。

## 一条成交提醒里有什么？

消息包含交易员、开平方向、合约、成交数量、成交均价、北京时间及交易员档案入口。通知中的「委托时间」取自公开记录。接收消息时的手机时间还包含观察台采集与微信投递的等待时间。

例如，某条通知会写明「示例交易员 · 开空 BTCUSDT」「成交数量 0.25 · 成交均价 82,000 USDT」。这里的数字仅用于演示格式。

| 字段 | 怎么读 |
| --- | --- |
| 开平方向 | 开多、平多、开空或平空。局部平仓需结合流水看数量。 |
| 委托时间 | 查看原记录显示的北京时间，配合档案中的完整查询截止核对。 |
| 交易员档案 | 查看已保存的公开成交流水、覆盖情况和仓位推算依据。 |

## 为什么我没收到，或者晚一点才收到？

先打开微信通知面板，看微信是否已激活、成交提醒开关是否开启，以及当前是否处于静默时段。静默期间会延后发送。若微信授权失效，按面板提示重新扫码，按提示在聊天里补发 init。

如果面板状态正常，再回观察台查看对应交易员是否启用采集、是否已有新成交，以及页面上的查询截止时间。实际到达时间受公开记录更新、站点采集和微信会话状态影响。历史导入和按日期回补不会补发提醒。

## 怎么暂停推送，或从一条通知继续复盘？

想少被打扰，可以在通知面板设置静默时段。想暂停本站提醒，可以直接关闭「TRADER WATCH 成交提醒」。关闭会取消该账号尚未发送的本站提醒。重新开启后从后续新成交开始接收。

收到提醒后，点开交易员档案，按合约、方向与时间找到对应记录。再用观察台的 K 线和交易轮次核对是否同一轮开平仓。公开记录里的单笔平仓不能说明该合约方向已全部平仓，核对时要看同轮累计数量和查询截止。
